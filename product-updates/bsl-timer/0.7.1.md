# BSL-Timer 0.7.1

Release date: 2026-09-22

## User-facing changes

- Automatic updates now show download progress.
- The application shows installation status after the download completes.
- Update failures are shown directly in the application UI.
- Free and Pro builds now use separate updater targets.
- Signed automatic update from 0.7.0 to 0.7.1 was successfully tested in a real installed build.

## Publication and promotion follow-up

- Prepare a website news post about the improved automatic update experience.
- Update BSL-Timer version information and download links on every platform where an older build is still published.
- Emphasize that future releases can now be installed directly from the application.
- Review Product Hunt and other previously used product pages for stale version information.
- Keep Free and Pro publication paths separate.
