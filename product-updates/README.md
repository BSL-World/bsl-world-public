# BSL-World Product Updates

This directory is the handoff point between product development and publication/promotion work.

Structure:

```text
product-updates/
└── <product-name>/
    └── <version>.md
```

Each release note records the user-visible result of a completed development iteration and the follow-up publication work that may still be needed.

Use these files when preparing:
- website news posts;
- release announcements;
- updates on product directories and launch platforms;
- refreshed download/version information;
- social posts and other promotion material.

Technical implementation details remain in each product's `CHANGELOG.md`.
