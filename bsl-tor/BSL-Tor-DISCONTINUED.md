# Where are the BSL-Tor installers?

The pre-built installers for BSL Tor have been permanently removed.

Development of this project is discontinued. It was a fully functional tool that installed the Tor Expert Bundle as a Windows service with a simple GUI for bridge management.

The decision to stop was personal, not technical, and is explained in detail here (in Russian):
[BSL-Tor: Прекращение разработки](https://bsl-world.ru/soft/bsl-tor-end)

This repository and its source code remain as a reference and a personal achievement. Built by a non-programmer with AI assistance and a belief that architecture matters.
