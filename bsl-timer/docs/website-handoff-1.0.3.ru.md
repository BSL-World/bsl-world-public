## Подписи обновления

Отсутствие Authenticode не означает отсутствие проверки подписи автообновления. Окончательные установщики Free и Pro имеют отдельные подписи Tauri/minisign (.exe.sig). По технической записи выпуска обе подписи криптографически проверены minisign-verify 0.2.5 с публичным ключом из tauri.conf.json. Эти подписи включены в latest.json. Не писать «установщик подписан Authenticode» или «издатель подтверждён Windows».

Манифест: https://bsl-world.ru/downloads/bsl-timer/latest.json

Один манифест обслуживает windows-x86_64 (совместимость со старым Free), windows-x86_64-free и windows-x86_64-pro.
