# BSL-Timer — план системы сигнала об окончании отсчёта

[English version](end-signal-plan.md)

## Целевая версия

Расширенная система сигнала об окончании отсчёта запланирована для
BSL-Timer 0.8.0. Точечные исправления окна About остаются задачами патч-версии
0.7.3.

## Необходимые пользовательские настройки

- Количество воспроизведений сигнала об окончании отсчёта.
- Интервал между воспроизведениями сигнала.
- Источник сигнала:
  - существующий стандартный сигнал;
  - встроенная библиотека сигналов BSL-World, работающая без подключения к
    интернету;
  - системные звуки Windows;
  - пользовательский аудиофайл, выбранный через стандартное окно выбора файла
    Windows.
- Устройство вывода звука, включая явный вариант «Устройство Windows по
  умолчанию».
- Кнопка «Проверить» или «Прослушать», использующая ещё не сохранённые настройки
  сигнала и устройства вывода.

## Поведение устройства вывода звука

Выбор устройства вывода имеет более низкий приоритет реализации, чем настройка
повторов и выбор звука, но остаётся обязательным требованием. Аудиоархитектура
должна поддерживать его с самого начала, а не привязывать воспроизведение
навсегда к текущему устройству Windows по умолчанию.

Выбранное устройство следует сохранять по устойчивому идентификатору, если
Windows его предоставляет. Если устройство отключено или больше недоступно,
BSL-Timer должен безопасно переключиться на устройство Windows по умолчанию,
сообщить об этом пользователю и продолжить работу. Список доступных устройств
следует обновлять при открытии Settings и, по возможности, после изменения
набора аудиоустройств в системе.

## Поведение источников сигнала

Встроенные сигналы BSL-World должны быть доступны без подключения к интернету.
Системные звуки Windows должны отображаться под понятными пользователю
названиями. Пользовательский файл необходимо выбирать через стандартное окно
Windows, проверять до сохранения настройки и разрешать предварительно
прослушать.

Повреждённый или недоступный пользовательский файл не должен мешать завершению
отсчёта или переходу таймера в состояние просрочки. Воспроизведение должно
безопасно перейти на резервный сигнал, а пользователь — получить понятное
сообщение об ошибке.

Создание собственной библиотеки сигналов BSL-World — с помощью Suno или другого
инструмента — является отдельной задачей по созданию контента. Она не должна
блокировать разработку архитектуры выбора и воспроизведения звука.

## Архитектурные ограничения

- Состояние таймера и расчёт просрочки не зависят от успешности
  аудиовоспроизведения.
- Последовательность повторных сигналов можно отменить; она не блокирует
  интерфейс программы.
- Планировщик повторов, источник звука и устройство вывода являются отдельными
  компонентами.
- Пользовательские настройки хранятся отдельно от текущего состояния таймера.
- Архитектура должна учитывать ситуацию, когда несколько таймеров завершаются
  почти одновременно, и управлять их совместным воспроизведением в соответствии
  с настройкой пользователя.
- Ни один источник сигнала не должен требовать подключения к интернету при
  обычном воспроизведении.

В существующей модели редакций уже предусмотрены возможности
`selectableSoundDevice`, `systemSounds` и `customSounds`, но сейчас они ошибочно
отключены для Free. При реализации их необходимо сделать доступными в обеих
редакциях. Текущий `SignalPlayer` создаёт один фиксированный сигнал через Web
Audio и отправляет его на устройство вывода по умолчанию. Этот жёстко заданный
путь следует заменить единым аудиосервисом, который сможет одинаково направлять
все поддерживаемые источники на выбранное устройство.

## Утверждённые продуктовые решения

1. Пользователь выбирает один из двух режимов повторения:
   - указать количество дополнительных повторов после первого сигнала;
   - указать промежуток времени, в течение которого сигнал будет повторяться.
2. Для количества повторов не устанавливается искусственный верхний предел.
   Значение `0` означает только первое воспроизведение без повторов. Реализация
   не должна заранее создавать в памяти всю последовательность при большом
   числе повторов.
3. Интервал отсчитывается между моментами начала соседних воспроизведений. Если
   длительность файла превышает интервал, очередная копия может начать звучать
   до окончания предыдущей.
4. Настройки сигнала хранятся отдельно для каждого таймера. Это относится к
   режиму и параметрам повторения, источнику сигнала и устройству вывода.
5. Программа воспроизводит пользовательский файл непосредственно из исходного
   расположения и не копирует его в каталог данных приложения. Если файл удалён
   или недоступен, используется встроенный резервный сигнал. Конкретный
   резервный звук будет выбран отдельно.
6. Гарантированно поддерживаются основные распространённые музыкальные форматы.
   Дополнительные, в том числе экзотические lossless-форматы, могут работать,
   если для них доступен системный декодер. Точный базовый список форматов
   определяется после выбора аудиобиблиотеки.
7. По умолчанию сигналы нескольких одновременно завершившихся таймеров могут
   звучать одновременно. В Settings добавляется флажок «Разрешать одновременное
   воспроизведение сигналов разных таймеров». При отключённом флажке сигналы
   воспроизводятся последовательно в порядке завершения таймеров.
8. Все функции, включая настройки звука и пресеты, доступны и в Free, и в Pro.
   Единственное функциональное отличие Pro — возможность создавать более одной
   вкладки таймера; Free ограничена одной вкладкой. При реализации существующий
   набор флагов редакций необходимо привести в соответствие с этим правилом.

## Технические детали, которые остаётся определить

- Единицы измерения, допустимый диапазон и значение интервала по умолчанию.
- Допустимый диапазон промежутка времени для временного режима повторения и его
  значение по умолчанию.
- Поведение уже начавшегося длинного файла при окончании заданного промежутка
  повторения. Предварительное предложение: не запускать новые повторы, но не
  обрывать уже начатое воспроизведение.
- Точный список гарантированно поддерживаемых форматов после выбора
  аудиобиблиотеки.
- Конкретный встроенный резервный сигнал.
