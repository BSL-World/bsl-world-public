# BSL-Timer 1.1.9 — локальная проверка переименования

5 ноября 2026. Точечное исправление потери фокуса поля имени вкладки при
периодическом захвате маски Glass. Поле исключается из маски через прозрачность
с сохранением видимости для механизма фокуса. Логика таймеров не меняется.

Версия согласована в package.json, package-lock.json, конфигурации Tauri,
Cargo.toml, Cargo.lock и «Что нового». Новый пункт добавлен в RU/EN с сохранением
накопленных сведений о предыдущих исправлениях.

Проверки исходников: 119 модульных тестов; 16 браузерных сценариев
Free/Pro × RU/EN × Glass/Light/Dark/System для переименования, Enter/Escape,
продолжающегося отсчёта, перехода в просрочку, Mute и мигания вкладок.
Переключение нескольких вкладок проверяется в Pro. Браузерный сценарий:
`npm run test:tab-rename`; ограничения описаны в
[tab-rename-regression.md](tab-rename-regression.md).
Обновлённое окно «Что нового» проверено на RU/EN в Small/Normal/Large.

Локальные установщики Free/Pro собраны и проверены в
`src-tauri/target/release-handoff/1.1.9/`.
Версии, SHA-256, соответствие редакций, наличие нативного Glass и исправления
в обоих упакованных frontend проверены. Отчёт: `candidate-status.json` в этой
папке. Authenticode: NotSigned; подписи обновлений для локальной приёмки не создавались.
Публикация, изменение производственного манифеста и установка на компьютер
пользователя этой подготовкой не выполняются. Проверка установленной версии
ожидает результата пользователя.

## Приёмка установленного приложения

1. Установить свою редакцию 1.1.9 поверх существующей, без удаления данных.
2. В режиме «Стекло» открыть переименование двойным кликом и вводить имя
   не менее пяти секунд. Проверить Enter и отмену изменённого имени через Escape.
3. Повторить во время короткого отсчёта, продолжая редактировать при переходе
   в просрочку. Отсчёт и мигание должны продолжаться, поле — сохранять фокус.
4. В Pro проверить переключение вкладок, Mute просроченного таймера и возврат
   к переименованному таймеру. После перезапуска проверить сохранённое имя.
