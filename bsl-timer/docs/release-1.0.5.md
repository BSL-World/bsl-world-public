# BSL-Timer 1.0.5 — живое время Информера

В 1.0.4 исправили нули при повторных напоминаниях о просрачке, но показания
остались статичными. Это не восстановило прежнее поведение Информера.
В 1.0.5 восстанавливается обновление показаний во время отображения карточки:
обратный отсчёт в предупреждениях за 15, 10 и 5 минут; растущая просрачка
после завершения и при повторных напоминаниях.

Тики исходного таймера передают отдельное обновление времени. Информер
принимает его только для своего eventId. Другие таймеры не меняют его
содержимое или цель нажатия. Обновление секунд не запускает изменение
размера окна. Время показа, звук, оформление, позиционирование и переход
по нажатию не менялись.

## Приёмка

1. Обновить установленную редакцию без удаления настроек.
2. Короткий таймер: при истечении Информер начинает с нуля, затем секунды
   просрачки растут, пока карточка видна.
3. Повторы через минуту: карточка начинает примерно с 00:01:00 / 00:02:00
   и продолжает обновляться каждую секунду.
4. Предупреждения за 15/10/5 минут: оставшееся время уменьшается,
   а не застывает на пороге предупреждения.
5. Pro: при выбранной другой вкладке показания принадлежат таймеру
   уведомления; нажатие открывает его. Проверить RU/EN и размеры шрифта.

Публикация и изменение производственного манифеста не выполняются.
